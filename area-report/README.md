# INCEPTION エリアレポート

住所検索、地図クリック、ドラッグで地点を選び、調査項目を選択してレポートを作成する独立したローカルWebアプリです。既存の会社ホームページのファイルは変更しません。

## 起動

Node.js 22.16以上（推奨24）で、このフォルダーから実行します。PC版の基本機能は同梱ランタイムでも動作します。公開用には `npm ci` で依存を導入します。

```powershell
node server.mjs
```

ブラウザーで http://127.0.0.1:4318/ を開きます。Windowsでは `start.cmd` も使えます。現在の実装はこのPCからのみ接続できる設定です。

## 使い方

1. 住所・町名を入力して検索し、候補を選ぶか、地図をクリックします。
2. 住所検索は代表点です。ピンをドラッグして建物の位置に合わせます。
3. 半径500m、1km、2kmから周辺施設の調査範囲を指定します。
4. 「調査項目・表紙を設定」で、項目・会社情報・宛名・表紙色・ロゴ・ご挨拶を設定します。
5. 「レポートを作成」で実データを取得し、プレビューで取得状況と出典を確認します。
6. 「PDF保存」でA4のPDFを直接ダウンロードします。Excel（.xlsx）とHTMLも保存できます。

「条件を保存」はこのブラウザーのlocalStorageに保存します。調査メモは地点ごとの一時情報で、地点を変更すると解除します。レポート本文はサーバーに保存しません。HTMLには外部地図画像が含まれるため、表示時のインターネット接続が必要です。

## データと実装範囲

|項目|取得元・状態|
|---|---|
|住所候補、標準地図、航空写真、標高|国土地理院。住所検索・標高の実通信を確認済み|
|駅・バス停、店舗、病院、学校、公共施設など|OpenStreetMap / Overpass。接続先が利用可能な環境で取得。提供元の障害・ネットワーク制限時は未取得として表示|
|用途地域・建ぺい率・容積率・区域区分|国土数値情報 A55 公開ファイル。宇治市・城陽市のみ、APIキー不要|
|人口・将来推計人口|国土交通省 XKT013。APIキー設定が必要。地点を含む250mメッシュ単位。円内の人口集計ではありません|
|津波浸水・土砂災害（数値・区域）|国土交通省 XKT028 / XKT029。APIキー設定が必要|
|洪水浸水想定区域|国土交通省 XKT026。APIキー設定が必要。原典の浸水深ランクを表示|
|その他の項目、周辺物件情報|自動データ連携は未実装。出典・基準日付きの調査メモで補完可能|

地図は地理院タイル、施設データはOSMへの出典を付けています。OSMは未収録の施設があります。施設の距離は代表座標までの直線距離で、徒歩距離・経路・所要時間ではありません。データがない場合を「施設なし」「災害リスクなし」と判定しません。地図の地点判定は土地全体の区域を保証するものではありません。

本アプリはアットホームのAPIや会員情報に接続していません。参考PDFのデータを他の住所に流用せず、商用レポートの図版も再配布しません。

## 国土交通省APIの接続

公式案内: https://www.reinfolib.mlit.go.jp/help/apiManual

1. 国土交通省でAPI利用申請を行い、キーを取得します。
2. `.env.example` を `.env` にコピーし、`REINFOLIB_API_KEY` にキーを設定します。
3. サーバーを再起動します。

キーはサーバー内からのみ送信し、ブラウザーには返しません。`.env` はGit管理対象外です。キー未設定の現在、国交省の実通信は未検証です。申請・契約等の外部手続きは自動実行しません。

## 外部通信

住所検索で入力した住所は国土地理院に送信します。施設調査の座標・半径・施設種別は設定されたOverpassサーバーに送信します。既定の接続先は、利用者の承認を受けたVK Maps（https://maps.mail.ru/osm/tools/overpass/api/interpreter）です。標高の座標は国土地理院へ、国交省API利用時は座標を含むタイル番号を国土交通省へ送信します。会社情報・宛名・ロゴ・調査メモはこれらのデータ提供元には送信しません。Google Fontsへのフォント要求があります。

Overpass URLはサーバーの `.env` で変更可能です。公開サービスの利用条件を確認し、事業運用時は契約サービスや自社サーバーへの切り替えを検討してください。OSMデータのライセンスはODbLです。

## 本番運用前に必要なこと

- データ提供元の利用条件、更新頻度、対象地域と契約の確認
- 未連携の統計・防災・都市計画・物件データの接続
- サーバーホスティング、認証、HTTPS、アクセス制限、利用量制御
- 元データとレポート出力の業務上の照合

既存の静的ホームページへファイルを置くだけでは、サーバーAPI部分は動作しません。公開用サーバーの構成が別途必要です。

## 検証

```powershell
node --test test/*.test.mjs
```

`test/e2e.cjs` はPlaywrightとChromeが利用できる環境で、住所検索・プレビュー・XLSX・PDF・スマートフォン幅を確認するためのスクリプトです。出力は `.gitignore` に含まれる `test-output/` に保存します。

### 施設取得の一時障害への対応

施設は項目ごとに取得し、同時接続は最大2件です。HTTP 429・502・503・504や通信タイムアウトは1回再試行します。成功した項目は1時間キャッシュし、取得日時を保持します。失敗した項目だけ未取得として表示します。提供元の障害が続く場合は、数分後に再作成してください。選択項目が多い場合、混雑時には数分かかることがあります。

## 申請不要で追加した調査（2026-09-19）

「調査項目・表紙を設定」→「申請不要の基本セット」でまとめて選択できます。

- 地震の揺れの超過確率：防災科研 J-SHIS 2024年（NIED作成版）、平均ケース・全地震の30年間超過確率。版の評価期間であり、レポート作成日から30年を再計算した値ではありません。
- 洪水ハザードマップ（図）：想定最大規模の公式画像と凡例を取得します。地点の浸水深数値・区域内外の判定はしません。
- 土砂災害ハザードマップ（図）：土石流・急傾斜地の崩壊・地すべりの3種類。画像未配信や通信失敗を表示し、未着色を安全と扱いません。
- 市区町村の総人口推移・一般世帯数：地理院の逆ジオコーディングで市区町村を特定し、統計ダッシュボードから直近6時点の利用可能値を取得。市全体の統計で、半径内や250mメッシュの集計ではありません。速報・確報、年次、単位を表示します。

新しい外部通信：調査座標をJ-SHISと国土地理院の逆ジオコーダへ送信し、市区町村コードを統計ダッシュボードへ送ります。ハザード地図は国土地理院へタイル座標で要求します。会社情報・宛名は送信しません。

ハザード画像と凡例は取得時にHTML内へ埋め込むため、後から表示内容が変わりません（背景地図は外部参照）。本図は自治体作成の重要事項説明用ハザードマップの代用にはできません。最新資料は自治体に確認してください。

出典・仕様：
- https://www.j-shis.bosai.go.jp/api-pshm-meshinfo
- https://dashboard.e-stat.go.jp/static/api
- https://disaportal.gsi.go.jp/hazardmap/copyright/opendata.html
- https://disaportal.gsi.go.jp/hazardmap/copyright/copyright.html

250mメッシュ人口等の国交省API連携は、引き続きキー取得後に実通信を確認します。

## 用途地域の公開ファイル取込み

宇治市・城陽市の用途地域（指定建ぺい率・指定容積率）と区域区分を、国土数値情報 A55 2024年度版の GeoJSON から抽出しています。キーなし・外部通信なしで地点判定します。基本セットにも含まれます。

- 原典時点：宇治市 2019年3月20日、城陽市 2023年7月20日・9月26日。公開年度は最新性を意味しません。
- 境界から約5m以内は隣接区域を含む候補として表示。敷地全体や道路条件による最終適用率の判定ではありません。
- 対象外・未収録・用途未指定を自動的に区別せず「未取得」と表示します。
- データは固定スナップショットです。自動更新は行いません。更新時は公式ファイルと自治体別の原典時点を確認して再取込みします。
- 原典 https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A55-2024.html （CC BY 4.0）。抽出・加工して利用。
- `data/sources/` に原典ZIPと自治体一覧、`data/planning-2024.json` に出典URL・ハッシュ・原典時点と抽出データを保存しています。

PDF生成はローカルのChromeとPlaywrightを利用します。このPCではCodex同梱のPlaywrightを使用します。他のPCへ移す場合はChromeとPlaywrightの導入が必要です。PDF用ブラウザーはスクリプトを無効化し、画像・フォントの取得先を地理院タイルとGoogle Fontsに制限しています。

## 周辺施設の自動保存・更新

宇治市・城陽市と周辺を含む範囲（北緯34.78〜35.00、東経135.70〜135.97）の施設を項目別に data/facilities/ へ保存します。レポートでは地点と半径で絞り込みます。サーバー起動時と稼働中1時間ごとに確認し、24時間を経過したデータを更新します。失敗時は前回の成功分と取得日時を保持し、レポートに更新未完了を明記します。PCやサーバーの停止中は更新せず、次回起動時に再開します。初回取得が失敗し保存分もない場合は従来の地点別取得を試します。市区町村境界そのものによる抽出ではなく、周辺の施設も含みます。

## Vercel公開版

Vercelプロジェクトのルートは `area-report`。GitHubの会社ホームページと別プロジェクトです。Node.js 24、`npm ci` で依存を導入します。`vercel.json` がAPIと静的ファイルへのアクセスをログイン必須のハンドラーへ送ります。

必須環境変数は `.env.example` を参照。APP_PASSWORD_HASHはランダムsaltとscrypt(password,salt,32)のhexをコロンで連結。SESSION_SECRETとCRON_SECRETは別々のランダム値を設定します。APIキー・.env・ログイン情報はGitへ追加しません。パスワード共有方式で個別ユーザー管理はありません。7日有効の署名Cookieを使い、ログアウトで削除します。

施設データは非公開Vercel Blobへ保存。毎日日本時間4時のCronで更新し、失敗した項目は前回成功分を維持します（実行開始時刻は遅れる場合があります）。PC起動は不要です。PDFも非公開Blobに保存し、10分有効の取得URLを発行します。作成から24時間経過したPDFは次回Cronで削除します。レポートの宛名・会社情報もPDFに含まれるため、保存期間中はクラウドに保管されます。アクセスURLは共有しないでください。

PDF処理中の外部接続は地理院タイルとGoogle Fontsに限定します。公開するAPIの操作にはログインを要求し、CronはCRON_SECRETを要求します。VercelとBlobの利用料はアカウントのプランと使用量によります。

会社業務でVercelへ本番公開する場合は、商用利用が可能なプランを使用してください。Hobbyは個人・非商用向けです。
